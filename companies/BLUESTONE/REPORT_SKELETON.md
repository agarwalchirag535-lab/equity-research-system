## Standing constraints on the assembled report

- **No buy / sell / hold, no target price as certainty, no position sizing** (`INSTRUCTIONS.md` §4 A19,
  doctrine §1c). S6 may say what the price implies and what would break the case; nothing further.
- **Findings are ranked by materiality to the investment case**, never by statement order (§1f).
- **Every contradiction that appears in an intermediate artifact must appear in the final report.**
  QC fails the report if one was silently resolved (doctrine §10).
- **If the earnings-quality gate returns *Cannot be relied upon*, section 18 is not written.** The verdict
  is the conclusion and the report ships on it.
- **If an unresolved Critical flag survives wave 7**, the report ships with the terminal state
  `UNINVESTABLE ON TRUST GROUNDS`. That is an ending, not a pause.
- **`waves/W1.7_newlisting_overlay.md` §8 is a prohibition register** and QC checks the report against it
  line by line.
